# Summoning body gestures

These three local Studio drafts reuse the imported True Seeing body-only cast
program in `../neuroclient/spell-studio-drafts.materialized.json`: Special1,
playback speed 1, release frame 8, hidden held equipment, disabled recovery,
and effect-anchored condition children. Each retains its native spell identity.
No projectile, arrival/departure effect, texture or new gesture is added.

Dismissal separately binds the imported counterspell actor-only Special1 recipe
through `../neuroclient/action-recipe-bindings.json`, with feedback disabled.
The existing causal compositor owns creature observation and terminal departure
at the authored effect anchor.
