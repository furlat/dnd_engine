# Engine Book Completion Matrix

This is the goal-level tracker for the NeuroDragon Dev Manual. It is not a
replacement for `engine_book/parity_matrix.md`; the parity matrix tracks
example-to-test rows, while this file tracks whether each subsystem is actually
ready to ship as part of the public developer manual.

## Status Legend

- `complete`: verified with a concrete source or command.
- `partial`: present, but not yet deep enough for the final goal.
- `needs-audit`: exists, but has not been studied from first principles.
- `missing`: required and not present.
- `not-started`: no meaningful work has begun.
- `n/a`: not applicable for this chapter or gate.

Do not mark a cell `complete` because a page or test file merely exists. A
complete cell needs evidence: source study, exact snippet execution, focused
tests, build output, route smoke checks, or Tommaso-approved scope decisions.
