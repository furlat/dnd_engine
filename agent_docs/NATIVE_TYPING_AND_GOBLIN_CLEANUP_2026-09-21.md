The user explicitly authorized closing the 266 native Pyright errors and the
goblin slash-overlay gap after the graphics cleanup. This is the current bounded
unit on `codex/recovery-design`; preserve the existing working tree.

## Contract and sequence

1. Reproduce and group the diagnostics by their actual owners. The retained
   baseline contains 266 errors and one warning across 249 native Python files.
   Broad keyword dictionaries account for many repeated constructor errors;
   this does not establish that every diagnostic is merely an annotation issue.
2. Repair native declarations and call sites where their actual contracts are
   already known: concrete argument names/types, finite vocabulary types,
   optional-value narrowing, tuple shapes and actual event/handler return types.
   Investigate undefined names, obsolete APIs and lifecycle cleanup as real
   potential behavior defects. Test any demonstrated runtime repair at its
   native event/state boundary.
3. Repair the missing goblin slash binding using the existing attack recipe,
   rig mapping and media mechanisms. Preserve attack/contact/damage timing.
   Reuse existing authored art; no new asset generation or spell authoring.
   Replay the saved opportunity-attack case in all four cameras and inspect
   both the body and the restored overlay.
4. Run the complete native typecheck with the existing configuration and project
   interpreter, then graphics/tooling typechecking, relevant architecture checks
   and active native/game regression lanes. Keep static checking separate from
   runtime evidence. Record commands, results and any real behavior corrections.

No checker-rule relaxation, ignored diagnostics, broad Any substitution, dynamic
attribute probes, late imports or new behavioral inheritance hierarchy. Type
annotations must describe the existing ECS composition. Preserve native subjectivity,
complete event lineages, required authoring/initialization fields, handler phases
and runtime validation semantics. Do not add defensive gameplay rules merely to
quiet a checker, or remove a required field to make inherited defaults convenient.

## Implemented result

Native typing is now **0 errors, 0 warnings**, across all 249 native Python files,
with the original Pyright configuration and installed checker. The starting
266 errors and one warning are resolved. Graphics, animation-review tooling and
the fixed-rig importer also typecheck with **0 errors, 0 warnings**.

The repeated errors were mostly imprecise constructor keyword dictionaries,
erased skill/ability/die vocabularies, and registry lookup return types. Repairs
retain concrete keywords, a small passive TypedDict where omission matters,
existing finite names and exact owning-template types. Seven attached aura/zone
models still require a supplied, non-null UUID anchor. Pydantic's required-value
sentinel expresses this without adding a default or reorganizing the models.

The map's spatial-owner protocol now describes the methods its stored owners
already provide; concrete mechanics stay in the existing spatial conditions.
The event-dependent finite-charge protocol moved from cold item data to its
only consumer, action execution, preserving the import DAG. An action may return
a canceled child Event, while a successful result remains an ActionEvent; the
annotations now represent that distinction without replacing child lineages.

One real runtime defect was reproduced and fixed: a vetoed Continual Flame
activation destroyed its anchor, then called a nonexistent unregister method.
The redundant call is removed. The regression verifies cancellation with no
remaining placed anchor, condition or light.
