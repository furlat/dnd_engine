# All-spell casting authoring — 4 October 2026

Human authorization: assign every available spell, review assignments for consistent
power progression, implement the selections and exact pixelated palette/material,
then export a persistent complete standard engine gallery. Add a modest arena
using original assets, with readable tiles and an unobstructed casting area.

## Boundaries and acceptance

Presentation input remains the existing recorded player sequence. Canonical spell
recipes, their explicit effect variants and action aliases must be accounted for.
Every ordinary modular cast selects a source motion, matching Magic2, zero or
more deliberate matching Effect layers, its actual existing spell palette and
source noise treatment. True Strike retains the real weapon attack with matching
hand accents. Fixed creature rigs keep their own source gestures and embedded
accents. Godot media remains the main delivery; Buffs are excluded.

Power scaling is visual: compact cantrips/quick casts, tighter low-level accents,
broader middle-level body energy, and selected major-spell signatures. Delivery,
repeat frequency and competing Godot geometry take priority over adding layers.
No spell rules, damage, actions, conditions or event types are added/changed.

## Ordered implementation

1. Inventory all loaded canonical/variant/alias rows against current content and
   actual owning files. Create a complete explicit assignment JSON/Markdown:
   clip, release/speed, source sockets, layers, palette/noise, level/visual budget,
   rationale, preparation synchronization, child attacks and export coverage.
   Original data and old recipe snapshots stay in the private working receipt.
2. Independent **anti-slop** and **anti-OOP/ECS/import-DAG** reviewers inspect the
   complete assignments and shared implementation proposal before application.
   Correct omissions, excessive flourishes and motion/delivery mismatches.
3. Use an offline generic authoring command to apply validated selections to
   existing recipe owners, preserving unrelated delivery/outcome tracks. The
   selection document is an authoring input, not a second runtime registry.
   Reuse existing StudioCast, StudioActorLayer, PaletteTreatment and pose-socket
   types. Resolve automatic owning palette while preserving authored gamma/noise;
   load existing noise through the same bounded palette path/cache. No per-spell
   renderer branches or generated painted variants.
4. Install only newly selected original sheets, with existing verified private
   asset installer and source/hash receipts. Keep original alpha, cell positions,
   eight facings and frame clocks. Validate actual rendered palette/noise, cache
   separation/seek, release sockets, aliases and fixed-rig separation. Run the
   relevant client/architecture checks and scoped typing; investigate real failures.
5. Export every spell through native recorded inputs and the standard four-camera
   engine gallery, with its existing handlers and main delivery. Select existing
   native histories first; capture missing histories once through ordinary engine
   actions. Persist inputs, traces, coverage, recipes/source metadata, videos and
   posters in the private art review archive, with a stable gallery link. Every
   spell/variant/alias gets a coverage row; disabled child-effect casts are shown
   through their actual owner sequence rather than an invented standalone cast.
6. Add simple arena dressing through existing scene/assets: real paving/wood,
   open central area, sparse peripheral scenery. Do not obscure actors, hit/death
   feedback or large area media. Record exact dressing choice. A representative
   scene review precedes the bulk export.

   Selected minimal treatment: existing `--floor wood` chooses original timber
   tiles. Native walls, cliffs, stairs and objects remain from the recorded
   histories. No synthetic scenery or changed occupancy/visibility is added.
   The first nine engine clips validate this floor before the bulk recording.
7. Independent final anti-slop and ECS/data reviews inspect implementation,
   assignment coverage and actual artifact evidence. Conclude after issues and
   export gaps are resolved. Update the recovery checkpoint and feature trace.

## Observable checks

- Every canonical spell has an assignment; every loaded alias/variant has explicit
  inheritance or separate authored selection, with no stale independent cast.
- Actual cast pixels use spell palette replacement and delivered noise; source
  alpha and actor/gear/shadow pixels remain intact. Shared sheets cannot leak
  another spell's palette, including backward seeks and repeat attacks.
- Projectile release follows the chosen pose/socket, preparation precedes release,
  and recipient reactions remain synchronized to existing delivery contact.
- True Strike attacks preserve real equipment/timing; fixed rigs use own gestures.
- Persistent gallery contains successful videos, saved player inputs, raw traces,
  handlers/coverage evidence and complete spell accounting; no silent omissions.

No external chat communication and no commit are part of this task.
