## 2. Source-backed causal finding

The frozen census is safe but insufficiently discriminating only at the
ordinary empty-argv seam:

1. ordinary enumeration parses status `Name`, `PPid`, and four UIDs;
2. it reads `cmdline` once;
3. raw or decoded empty argv plus a still-present `/proc/<pid>` directory
   becomes a deterministic `argv-empty` error;
4. `process_entry_present` is a directory stat, not a generation identity;
5. starttime, complete candidate status, cgroup, parent/PID1, exe/cwd, and
   initial/final snapshots occur only after nonempty argv identifies the
   systemd-PAM candidate;
6. existing pure controls do not enter the ordinary empty-argv branch.

The current nonzero is therefore correct. It cannot establish whether a
present empty entry is a zombie, a live process exposing an empty argv
region, an owned helper, a packet process, or a process that will disappear.

The documentation establishes:

- zombie `cmdline` reads zero bytes;
- a running process can alter the argv memory/range exposed by `cmdline`;
- stat field 3 is State, field 4 is PPid, and field 22 is starttime;
- status exposes State, Pid/Tgid, PPid, and four UIDs;
- a terminated un-waited child remains a zombie;
- `execve` preserves PID but does not prove why an observed cmdline was empty;
- cgroup records membership;
- exe/cwd readlinks are ptrace-gated and may be unavailable when a
  multithreaded process's main thread has terminated.

Consequently, persistent empty argv and readlink failure while the entry
remains present cannot become a clean disposition.

### 3.3 Exact stat record

Parse `/proc/<pid>/stat` without splitting inside parenthesized `comm`.
Require and record:

- field 1 PID, equal to the enumerated PID;
- field 2 comm;
- field 3 State;
- field 4 PPid;
- field 5 process group;
- field 6 session;
- field 22 starttime.

Missing prefix, missing closing parenthesis, insufficient fields, malformed
integer, or PID mismatch is a read error. Stat State has its own exact grammar:
one character from the documented stat alphabet
`R/S/D/Z/T/t/X/x/K/W/P/I`. Its nonterminal set is
`R/S/D/T/t/K/W/P/I`; its terminal-present set is `Z/X/x`. Empty,
multi-character, or any other one-character stat State is a deterministic
`stat-state` error for both targets and ancestors.

Starttime is the binding generation. PID alone is never sufficient.

### 3.4 Exact status record

Require and record:

- `Name`;
- `State`, including the leading state code;
- `Tgid`;
- `Pid`;
- `PPid`;
- exactly four `Uid` integers.

`Pid` and `Tgid` must equal the enumerated process PID. Status PPid must
equal both surrounding stat PPids. Effective UID must remain equal to the
census effective UID. A different UID is skipped only before any
same-euid candidate evidence is required; an UID change within a composite or
between composites is nonzero.

Status State has a separate exact grammar. Its leading code must be exactly
one character from the proc_pid_status alphabet `R/S/D/T/t/Z/X`. Its
nonterminal set is `R/S/D/T/t`; its terminal-present set is `Z/X`. Stat-only
`I/K/W/P/x` are not status-compatible values. Empty, multi-character,
malformed, or any other one-character status State is nonzero independently
of stat validation.

Nonterminal State changes are recorded only when each parser's observation is
inside its own nonterminal set; they do not claim exec. Any target or ancestor
stat `Z/X/x`, or status `Z/X`, while the entry remains present is terminal and
nonzero. A valid nonterminal companion observation cannot clear a terminal
observation from the other parser.

class ProtocolFault(ValueError):
    pass


def normalized(value: str) -> str:
    return value.replace("\\", "/")


def basename(value: str) -> str:
    return os.path.basename(normalized(value))


def status_fields(pid: int) -> dict[str, str]:
    text = (PROC / str(pid) / "status").read_text(
        encoding="utf-8",
        errors="surrogateescape",
    )
    values: dict[str, str] = {}
    for line in text.splitlines():
        key, separator, value = line.partition(":")
        if separator:
            values[key] = value.strip()
    return values


def integer_field(values: dict[str, str], key: str, count: int) -> list[int]:
    try:
        result = [int(item, 10) for item in values[key].split()]
    except Exception as exc:
        raise ProtocolFault(f"malformed {key} integer: {exc}") from exc
    if len(result) != count:
        raise ProtocolFault(f"{key} must contain exactly {count} integers")
    return result


def basic_status(values: dict[str, str]) -> dict[str, object]:
    return {
        "name": values["Name"],
        "ppid": int(values["PPid"].split()[0]),
        "uids": integer_field(values, "Uid", 4),
    }

    result = basic_status(values)
    result.update(
        {

def status_values_from_text(text: str) -> dict[str, str]:
    values: dict[str, str] = {}
    for line in text.splitlines():
        key, separator, value = line.partition(":")
        if not separator:
            continue
        if key in values:
            raise ProtocolFault(f"duplicate status field {key}")
        values[key] = value.strip()
    return values


def one_decimal(values: dict[str, str], key: str) -> int:
    tokens = values[key].split()
    if len(tokens) != 1:
        raise ProtocolFault(f"{key} must contain exactly one integer")
    try:
        value = int(tokens[0], 10)
    except Exception as exc:
        raise ProtocolFault(f"malformed status integer {key}: {exc}") from exc
    if value < 0:
        raise ProtocolFault(f"{key} must be nonnegative")
    return value


def parse_status_values(
    values: dict[str, str],
    *,
    expected_pid: int,
) -> dict[str, object]:
    required = ("Name", "State", "Tgid", "Pid", "PPid", "Uid")
    for key in required:
        if key not in values:
            raise ProtocolFault(f"status missing {key}")
    state_tokens = values["State"].split()
    if not state_tokens:
        raise ProtocolFault("status State was empty")
    state = state_tokens[0]
    if len(state) != 1 or state not in STATUS_STATES:
        raise ProtocolFault(f"invalid status State {state!r}")
    pid = one_decimal(values, "Pid")
    tgid = one_decimal(values, "Tgid")
    ppid = one_decimal(values, "PPid")
    uids = integer_field(values, "Uid", 4)
    if any(uid < 0 for uid in uids):
        raise ProtocolFault("Uid values must be nonnegative")
    if pid != expected_pid or tgid != expected_pid:
        raise ProtocolFault(
            f"status Pid/Tgid {pid}/{tgid} did not match {expected_pid}"
        )
    return {
        "name": values["Name"],
        "pid": pid,
        "ppid": ppid,
        "state": state,
        "tgid": tgid,
        "uids": uids,
        "values": values,
    }

    return parse_status_values(
        status_values_from_text(text),
        expected_pid=expected_pid,
    )


def parse_stat_text(text: str, *, expected_pid: int) -> dict[str, object]:
    prefix = f"{expected_pid} ("
    if not text.startswith(prefix):
        raise ProtocolFault("stat PID prefix did not match the captured PID")
    closing = text.rfind(")")
    if closing < len(prefix):
        raise ProtocolFault("stat comm field had no closing parenthesis")
    tail = text[closing + 1 :]
    if not tail.startswith(" "):
        raise ProtocolFault("stat State separator was missing")
    if len(tail) == 1 or tail[1].isspace():
        raise ProtocolFault("stat State was empty")
    fields = tail.split()
    if len(fields) <= 19:
        raise ProtocolFault("stat did not contain field 22 starttime")
    state = fields[0]
    if len(state) != 1 or state not in STAT_STATES:
        raise ProtocolFault(f"invalid stat State {state!r}")
    try:
        ppid = int(fields[1], 10)
        pgrp = int(fields[2], 10)
        session = int(fields[3], 10)
        starttime = int(fields[19], 10)
    except Exception as exc:
        raise ProtocolFault(f"malformed stat integer: {exc}") from exc
    if ppid < 0 or pgrp < 0 or session < 0 or starttime <= 0:
        raise ProtocolFault("stat identity integers were out of range")
    return {
        "comm": text[len(prefix) : closing],
        "pgrp": pgrp,
        "pid": expected_pid,
        "ppid": ppid,
        "session": session,
        "starttime": starttime,
        "state": state,
    }


def parse_cgroup_text(text: str) -> dict[str, object]:
    lines = text.splitlines()
    if not lines:
        raise ProtocolFault("cgroup contained zero valid lines")
    parsed: list[dict[str, object]] = []
    for line in lines:
        fields = line.split(":")
        if len(fields) != 3:
            raise ProtocolFault("cgroup line did not contain three fields")
        hierarchy, controllers, path = fields
        if not hierarchy.isascii() or not hierarchy.isdecimal():
            raise ProtocolFault("cgroup hierarchy ID was malformed")
        if controllers and any(not item for item in controllers.split(",")):
            raise ProtocolFault("cgroup controller list was malformed")
        if not path:
            raise ProtocolFault("cgroup path was empty")
        parsed.append(
            {
                "controllers": controllers,
                "hierarchy": int(hierarchy, 10),
                "path": path,
            }
        )
    return {"lines": parsed, "raw": text}


def parse_canonical_environment_integer(
    environment: dict[str, str],
    *,
    key: str,
    maximum: int,
) -> int:
    if key not in environment:
        raise ProtocolFault(f"missing outer-owner environment key {key}")
    raw = environment[key]
    if not raw:
        raise ProtocolFault(f"outer-owner environment key {key} was empty")
    if (
        not raw.isascii()
        or not raw.isdecimal()
        or raw.startswith("0")
        or any(character < "0" or character > "9" for character in raw)
    ):
        raise ProtocolFault(f"outer-owner environment key {key} was malformed")
    value = int(raw, 10)
    if value < 1 or value > maximum:
        raise ProtocolFault(f"outer-owner environment key {key} was out of range")
    return value


def parse_outer_owner_environment(
    environment: dict[str, str],
) -> tuple[int, int]:
    return (
        parse_canonical_environment_integer(
            environment,
            key=OUTER_PID_KEY,
            maximum=OUTER_PID_MAX,
        ),
        parse_canonical_environment_integer(
            environment,
            key=OUTER_STARTTIME_KEY,
            maximum=OUTER_STARTTIME_MAX,
        ),
    )


def contains_pair(argv: list[str], first: str, second: str) -> bool:
    return any(
        argv[index] == first and argv[index + 1] == second
        for index in range(len(argv) - 1)
    )


def npm_process(argv: list[str]) -> bool:
    return bool(argv) and (
        basename(argv[0]) in NPM_BASENAMES
        or any(basename(token) in {"npm-cli.js", "npx-cli.js"} for token in argv)
    )


def argv_classes(argv: list[str]) -> list[str]:
    result: list[str] = []
    argv0 = basename(argv[0])
    normalized_tokens = [normalized(token) for token in argv]
    is_npm = npm_process(argv)

    if any(basename(token) == "hosted-game-smoke.mjs" for token in argv) or (
        is_npm and "hosted-game:smoke" in argv
    ):
        result.append("hosted-smoke")
    if contains_pair(argv, "-m", "uvicorn") and "server.game_gateway:app" in argv:
        result.append("gateway")
    if (
        contains_pair(argv, "-m", "uvicorn")
        and "server.event_server:app" in argv
        and "--uds" in argv
    ):
        result.append("hosted-worker")
    if contains_pair(argv, "-m", "server.event_server") or (
        contains_pair(argv, "-m", "uvicorn")
        and "server.event_server:app" in argv
    ):
        result.append("event-server")
    if (
        contains_pair(argv, "-m", "server.game_creation_preview_worker")
        and "--serve" in argv
    ):
        result.append("preview-worker")
    if (
        any(token.endswith("/node_modules/vite/bin/vite.js") for token in normalized_tokens)
        or any(
            token == "node_modules/.bin/vite"
            or token.endswith("/node_modules/.bin/vite")
            for token in normalized_tokens
        )
        or argv0 == "vite"
    ):
        result.append("vite")
    if (
        argv0 == "playwright"
        or any(
            "/node_modules/playwright-core/" in token
            or "/node_modules/playwright/" in token
            for token in normalized_tokens
        )
    ):
        result.append("playwright")
    if argv0 in CHROMIUM_BASENAMES:
        result.append("chromium")
    return sorted(set(result))


def classes(argv: list[str], executable: str, cwd: str) -> list[str]:
    result = argv_classes(argv)
    argv0 = basename(argv[0])
    normalized_executable = normalized(executable)
    is_npm = npm_process(argv)

    if (
        (is_npm and "dev" in argv and cwd == APP_ROOT)
        or (
            is_npm
            and "dev" in argv
            and cwd == NEUROCLIENT_ROOT
            and any(
                argv[index] == "--prefix" and argv[index + 1] in {"app", "./app"}
                for index in range(len(argv) - 1)
            )
        )
        or (
            argv0 in SHELL_BASENAMES
            and len(argv) >= 3
            and argv[-2:] == ["-c", "vite"]
            and cwd == APP_ROOT
        )
    ):
        result.append("vite")
    executable_basename = basename(normalized_executable)
    if (
        executable_basename in CHROMIUM_BASENAMES
        or (
            "/ms-playwright/" in normalized_executable
            and executable_basename == "chrome"
        )
    ):
        result.append("chromium")
    return sorted(set(result))


def read_text_record(
    errors: list[dict[str, object]],
    *,
    pid: int,
    name: str,
    stage: str,
    allow_absent: bool = False,
) -> tuple[str | None, bool]:
    try:
        return (PROC / str(pid) / name).read_text(
            encoding="utf-8",
            errors="surrogateescape",
        ), False
    except (FileNotFoundError, ProcessLookupError) as exc:
        if not process_entry_present(pid):
            if allow_absent:
                return None, True
            append_error(
                errors,
                pid=pid,
                stage=stage,
                detail="required process generation disappeared",
            )
            return None, True
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
    return None, False


def read_bytes_record(

) -> tuple[bytes | None, bool]:
    try:

            append_error(

                pid=pid,
                stage=stage,
                detail="required process generation disappeared",
            )
            return None, True
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
    return None, False


def read_stat_record(

        )

def decode_cmdline(raw_argv: bytes) -> list[str]:
    return [
        token.decode("utf-8", errors="surrogateescape")
        for token in raw_argv.split(b"\0")
        if token
    ]


def decode_cmdline_receipt(
    raw_argv: bytes | None,
    *,
    read_failure: str | None = None,
    decode_failure: str | None = None,
) -> dict[str, object]:
    if read_failure is not None:
        raise ProtocolFault(f"cmdline read failure: {read_failure}")
    if raw_argv is None:
        raise ProtocolFault("cmdline raw receipt was missing")
    if decode_failure is not None:
        raise ProtocolFault(f"cmdline decode failure: {decode_failure}")
    return {"argv": decode_cmdline(raw_argv), "raw_argv": raw_argv}


def parse_cgroup_receipt(
    text: str | None,
    *,
    read_failure: str | None = None,
) -> dict[str, object]:
    if read_failure is not None:
        raise ProtocolFault(f"cgroup read failure: {read_failure}")
    if text is None:
        raise ProtocolFault("cgroup raw receipt was missing")
    return parse_cgroup_text(text)


def read_cmdline_record(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
) -> tuple[dict[str, object] | None, bool]:
    raw_argv, absent = read_bytes_record(
        errors,
        pid=pid,
        name="cmdline",
        stage=stage,
    )
    if raw_argv is None:
        return None, absent
    try:
        record = decode_cmdline_receipt(raw_argv)
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None, False
    return record, False


def read_cgroup_record(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
) -> tuple[dict[str, object] | None, bool]:
    text, absent = read_text_record(
        errors,
        pid=pid,
        name="cgroup",
        stage=stage,
    )
    if text is None:
        return None, absent
    try:
        return parse_cgroup_receipt(text), False
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None, False


def state_errors(
    *,
    stat_state: str,
    status_state: str,
    stat_after_state: str | None = None,
) -> list[str]:
    result: list[str] = []
    if stat_state == "Z":
        result.append("stat-zombie")
    elif stat_state in {"X", "x"}:
        result.append("stat-dead-present")
    if status_state == "Z":
        result.append("status-zombie")
    elif status_state == "X":
        result.append("status-dead-present")
    if stat_after_state == "Z":
        result.append("stat-after-zombie")
    elif stat_after_state in {"X", "x"}:
        result.append("stat-after-dead-present")
    return result


def append_state_errors(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
    stat_state: str,
    status_state: str,
    stat_after_state: str | None = None,
) -> None:
    for state_error in state_errors(
        stat_state=stat_state,
        status_state=status_state,
        stat_after_state=stat_after_state,
    ):
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=state_error,
        )


def validate_stat_status_pair(
    stat_record: dict[str, object],
    status_record: dict[str, object],
) -> None:
    if stat_record["pid"] != status_record["pid"]:
        raise ProtocolFault("stat/status PID contradiction")
    if stat_record["ppid"] != status_record["ppid"]:
        raise ProtocolFault("stat/status PPid contradiction")


def validate_stat_identity_sandwich(
    before: dict[str, object],
    after: dict[str, object],
) -> None:
    for key in ("pid", "starttime", "ppid", "pgrp", "session"):
        if before[key] != after[key]:
            raise ProtocolFault(f"stat sandwich changed {key}")


def validate_stat_sandwich(
    before: dict[str, object],
    after: dict[str, object],
) -> None:
    validate_stat_identity_sandwich(before, after)
    if (
        before["state"] not in STAT_NONTERMINAL_STATES
        or after["state"] not in STAT_NONTERMINAL_STATES
    ):
        raise ProtocolFault("stat sandwich contained terminal State")


def validate_status_transition(
    initial: dict[str, object],
    final: dict[str, object],
) -> None:
    for key in ("pid", "tgid", "ppid", "uids"):
        if initial[key] != final[key]:
            raise ProtocolFault(f"status transition changed {key}")
    if (
        initial["state"] not in STATUS_NONTERMINAL_STATES
        or final["state"] not in STATUS_NONTERMINAL_STATES
    ):
        raise ProtocolFault("status transition contained terminal State")


def capture_generation_node(
    errors: list[dict[str, object]],
    *,
    pid: int,
    label: str,
) -> dict[str, object] | None:
    before, _ = read_stat_record(
        errors,
        pid=pid,
        stage=f"{label}-stat-before",
    )
    status_record, _ = read_status_record(
        errors,
        pid=pid,
        stage=f"{label}-status",
    )
    after, _ = read_stat_record(
        errors,
        pid=pid,
        stage=f"{label}-stat-after",
    )
    if before is None or status_record is None or after is None:
        return None
    try:
        validate_stat_identity_sandwich(before, after)
        validate_stat_status_pair(before, status_record)
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=f"{label}-identity",
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None
    append_state_errors(
        errors,
        pid=pid,
        stage=f"{label}-state",
        stat_state=str(before["state"]),
        status_state=str(status_record["state"]),
        stat_after_state=str(after["state"]),
    )
    return {
        "pid": pid,
        "ppid": int(before["ppid"]),
        "starttime": int(before["starttime"]),
        "stat_after": after,
        "stat_before": before,
        "status": status_record,
    }


def capture_ancestry(
    errors: list[dict[str, object]],
    *,
    start_pid: int,
    label: str,
) -> list[dict[str, object]] | None:
    nodes: list[dict[str, object]] = []
    captured: set[int] = set()
    current = start_pid
    while True:
        if current <= 0:
            append_error(
                errors,
                pid=current,
                stage=f"{label}-ancestry",
                detail="ancestry reached nonpositive PID before PID 1",
            )
            return None
        if current in captured:
            append_error(
                errors,
                pid=current,
                stage=f"{label}-ancestry",
                detail="ancestry cycle detected",
            )
            return None
        captured.add(current)
        node = capture_generation_node(
            errors,
            pid=current,
            label=f"{label}-ancestor-{len(nodes)}",
        )
        if node is None:
            return None
        nodes.append(node)
        if current == 1:
            if int(node["ppid"]) != 0:
                append_error(
                    errors,
                    pid=1,
                    stage=f"{label}-ancestry",
                    detail="PID 1 had nonzero PPid",
                )
                return None
            return nodes
        parent = int(node["ppid"])
        if parent <= 0:
            append_error(
                errors,
                pid=current,
                stage=f"{label}-ancestry",
                detail="ancestry terminated before PID 1",
            )
            return None
        current = parent


def ancestry_identity(
    ancestry: list[dict[str, object]],
) -> list[dict[str, int]]:
    return [
        {
            "pid": int(node["pid"]),
            "ppid": int(node["ppid"]),
            "starttime": int(node["starttime"]),
        }
        for node in ancestry
    ]


def ancestry_contains_generation(
    ancestry: list[dict[str, object]],
    *,
    pid: int,
    starttime: int,
) -> tuple[bool, int | None]:
    for index, node in enumerate(ancestry):
        if int(node["pid"]) == pid and int(node["starttime"]) == starttime:
            return True, index
    return False, None


def read_outer_owner(
    errors: list[dict[str, object]],
    *,
    outer_pid: int,
    outer_starttime: int,
    inspector_ancestry: list[dict[str, object]],
) -> dict[str, object] | None:
    owner = capture_generation_node(
        errors,
        pid=outer_pid,
        label="outer-owner",
    )
    if owner is None:
        return None
    initial_cgroup, _ = read_cgroup_record(
        errors,
        pid=outer_pid,
        stage="outer-owner-cgroup-initial",
    )
    owner_ancestry = capture_ancestry(
        errors,
        start_pid=outer_pid,
        label="outer-owner",
    )
    final_cgroup, _ = read_cgroup_record(
        errors,
        pid=outer_pid,
        stage="outer-owner-cgroup-final",
    )
    closing_owner = capture_generation_node(
        errors,
        pid=outer_pid,
        label="outer-owner-closing",
    )
    if (
        initial_cgroup is None
        or final_cgroup is None
        or owner_ancestry is None
        or closing_owner is None
    ):
        return None
    try:
        validate_outer_owner_bundle(
            owner=owner,
            initial_cgroup=initial_cgroup,
            final_cgroup=final_cgroup,
            owner_ancestry=owner_ancestry,
            closing_owner=closing_owner,
            outer_pid=outer_pid,
            outer_starttime=outer_starttime,
            inspector_ancestry=inspector_ancestry,
        )
    except Exception as exc:
        append_error(
            errors,
            pid=outer_pid,
            stage="outer-owner-coherence",
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None
    in_inspector_chain, inspector_index = ancestry_contains_generation(
        inspector_ancestry,
        pid=outer_pid,
        starttime=outer_starttime,
    )
    if not in_inspector_chain:
        append_error(
            errors,
            pid=outer_pid,
            stage="outer-owner-inspector-chain",
            detail="outer-owner generation was absent from inspector ancestry",
        )
        return None
    return {
        "ancestry": ancestry_identity(owner_ancestry),
        "cgroup": initial_cgroup,
        "inspector_index": inspector_index,
        "pid": outer_pid,
        "starttime": outer_starttime,
    }


def generation_node_identity(node: dict[str, object]) -> dict[str, object]:
    status = node.get("status")
    before = node.get("stat_before")
    after = node.get("stat_after")
    if not isinstance(status, dict) or not isinstance(before, dict) or not isinstance(after, dict):
        raise ProtocolFault("outer-owner node lacked a complete identity receipt")
    return {
        "pid": node.get("pid"),
        "ppid": node.get("ppid"),
        "starttime": node.get("starttime"),
        "stat_before": {
            key: before.get(key)
            for key in ("pid", "ppid", "pgrp", "session", "starttime")
        },
        "stat_after": {
            key: after.get(key)
            for key in ("pid", "ppid", "pgrp", "session", "starttime")
        },
        "status": {
            key: status.get(key)
            for key in ("pid", "tgid", "ppid", "uids")
        },
    }


def validate_outer_owner_bundle(
    *,
    owner: dict[str, object],
    initial_cgroup: dict[str, object],
    final_cgroup: dict[str, object],
    owner_ancestry: list[dict[str, object]],
    closing_owner: dict[str, object],
    outer_pid: int,
    outer_starttime: int,
    inspector_ancestry: list[dict[str, object]],
) -> None:
    if not isinstance(owner, dict):
        raise ProtocolFault("outer-owner initial receipt was missing")
    if not isinstance(closing_owner, dict):
        raise ProtocolFault("outer-owner closing receipt was missing")
    if not isinstance(owner_ancestry, list):
        raise ProtocolFault("outer-owner ancestry receipt was missing")
    if not isinstance(inspector_ancestry, list):
        raise ProtocolFault("inspector ancestry receipt was missing")
    if not owner_ancestry:
        raise ProtocolFault("outer-owner ancestry was incomplete")
    pure_validate_ancestry(owner_ancestry, outer_pid)
    if not inspector_ancestry:
        raise ProtocolFault("inspector ancestry was incomplete")
    pure_validate_ancestry(inspector_ancestry, int(inspector_ancestry[0]["pid"]))
    expected = generation_node_identity(owner)
    ancestry_head = generation_node_identity(owner_ancestry[0])
    closing = generation_node_identity(closing_owner)
    if expected["pid"] != outer_pid or expected["starttime"] != outer_starttime:
        raise ProtocolFault("outer-owner metadata generation mismatch")
    if ancestry_head != expected:
        raise ProtocolFault("outer-owner ancestry head changed identity")
    if closing != expected:
        raise ProtocolFault("outer-owner closing snapshot changed identity")
    if not isinstance(initial_cgroup.get("raw"), str) or not isinstance(
        final_cgroup.get("raw"), str
    ):
        raise ProtocolFault("outer-owner cgroup receipt was incomplete")
    if initial_cgroup != final_cgroup:
        raise ProtocolFault("outer-owner cgroup changed during receipt")
    in_inspector_chain, _ = ancestry_contains_generation(
        inspector_ancestry,
        pid=outer_pid,
        starttime=outer_starttime,
    )
    if not in_inspector_chain:
        raise ProtocolFault("outer-owner generation was absent from inspector ancestry")


def readlink_result(
    entry: Path,
    *,
    pid: int,
    stage: str,
) -> tuple[str | None, dict[str, object] | None, bool]:
    try:
        return os.readlink(entry / stage), None, False
    except (FileNotFoundError, ProcessLookupError) as exc:
        if not process_entry_present(pid):
            return None, None, True
        return None, failure(stage, exc), False
    except Exception as exc:
        return None, failure(stage, exc), False


def process_starttime(pid: int) -> int:
    text = (PROC / str(pid) / "stat").read_text(
        encoding="utf-8",
        errors="surrogateescape",
    )
    parsed = parse_stat_text(text, expected_pid=pid)
    if parsed["state"] in STAT_TERMINAL_STATES:
        raise ProtocolFault("terminal stat State in systemd-PAM snapshot")
    return int(parsed["starttime"])


def read_required_starttime(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
) -> int | None:
    try:
        return process_starttime(pid)
    except (FileNotFoundError, ProcessLookupError) as exc:
        detail = (
            f"{type(exc).__name__}: {exc}"
            if process_entry_present(pid)
            else "candidate process disappeared before starttime was read"
        )
    except Exception as exc:
        detail = f"{type(exc).__name__}: {exc}"
    append_error(errors, pid=pid, stage=stage, detail=detail)
    return None


def read_required_status(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
) -> dict[str, str] | None:
    try:
        values = status_fields(pid)
        parsed = parse_status_values(values, expected_pid=pid)
        if parsed["state"] in STATUS_TERMINAL_STATES:
            raise ProtocolFault("terminal status State in systemd-PAM snapshot")
        return values
    except (FileNotFoundError, ProcessLookupError) as exc:
        detail = (
            f"{type(exc).__name__}: {exc}"
            if process_entry_present(pid)
            else "required related process disappeared before status was read"
        )
    except Exception as exc:
        detail = f"{type(exc).__name__}: {exc}"
    append_error(errors, pid=pid, stage=stage, detail=detail)
    return None


def read_required_cmdline(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
) -> tuple[bytes, list[str]] | None:
    try:
        raw_argv = (PROC / str(pid) / "cmdline").read_bytes()
    except (FileNotFoundError, ProcessLookupError) as exc:
        detail = (
            f"{type(exc).__name__}: {exc}"
            if process_entry_present(pid)
            else "candidate process disappeared before argv was read"
        )
        append_error(errors, pid=pid, stage=stage, detail=detail)
        return None
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None
    if not raw_argv:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail="candidate cmdline was empty",
        )
        return None
    argv = [
        token.decode("utf-8", errors="surrogateescape")
        for token in raw_argv.split(b"\0")
        if token
    ]
    if not argv:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail="candidate decoded argv was empty",
        )
        return None
    return raw_argv, argv


def read_required_cgroup(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
) -> str | None:
    try:
        text = (PROC / str(pid) / "cgroup").read_text(
            encoding="utf-8",
            errors="surrogateescape",
        )
    except (FileNotFoundError, ProcessLookupError) as exc:
        detail = (
            f"{type(exc).__name__}: {exc}"
            if process_entry_present(pid)
            else "candidate process disappeared before cgroup was read"
        )
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=detail,
        )
        return None
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None
    try:
        parse_cgroup_text(text)
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None
    return text.rstrip("\n")


def read_candidate_snapshot(
    errors: list[dict[str, object]],
    *,
    pid: int,
    label: str,
) -> dict[str, object] | None:
    start_before = read_required_starttime(
        errors,
        pid=pid,
        stage=f"systemd-pam-{label}-starttime-before",
    )
    target_values = read_required_status(
        errors,
        pid=pid,
        stage=f"systemd-pam-{label}-target-status",
    )
    cmdline = read_required_cmdline(
        errors,
        pid=pid,
        stage=f"systemd-pam-{label}-argv",
    )
    cgroup = read_required_cgroup(
        errors,
        pid=pid,
        stage=f"systemd-pam-{label}-cgroup",
    )

    target: dict[str, object] | None = None
    parent: dict[str, object] | None = None
    pid1: dict[str, object] | None = None
    if target_values is not None:
        try:
            target = candidate_status(target_values)
        except Exception as exc:
            append_error(
                errors,
                pid=pid,
                stage=f"systemd-pam-{label}-target-status",
                detail=f"{type(exc).__name__}: {exc}",
            )
    if target is not None:
        parent_pid = int(target["ppid"])
        parent_values = read_required_status(
            errors,
            pid=parent_pid,
            stage=f"systemd-pam-{label}-parent-status",
        )
        if parent_values is not None:
            try:
                parent = basic_status(parent_values)
                parent["pid"] = parent_pid
            except Exception as exc:
                append_error(
                    errors,
                    pid=parent_pid,
                    stage=f"systemd-pam-{label}-parent-status",
                    detail=f"{type(exc).__name__}: {exc}",
                )
    pid1_values = read_required_status(
        errors,
        pid=1,
        stage=f"systemd-pam-{label}-pid1-status",
    )
    if pid1_values is not None:
        try:
            pid1 = basic_status(pid1_values)
            pid1["pid"] = 1
        except Exception as exc:
            append_error(
                errors,
                pid=1,
                stage=f"systemd-pam-{label}-pid1-status",
                detail=f"{type(exc).__name__}: {exc}",
            )
    start_after = read_required_starttime(
        errors,
        pid=pid,
        stage=f"systemd-pam-{label}-starttime-after",
    )
    if (
        start_before is None
        or start_after is None
        or target is None
        or cmdline is None
        or cgroup is None
        or parent is None
        or pid1 is None
    ):
        return None
    if start_before != start_after:
        append_error(
            errors,
            pid=pid,
            stage=f"systemd-pam-{label}-generation",
            detail=f"starttime changed from {start_before} to {start_after}",
        )
        return None
    raw_argv, argv = cmdline
    return {
        "argv": argv,
        "cgroup": cgroup,
        "packet_argv_classes": argv_classes(argv),
        "parent": parent,
        "pid1": pid1,
        "raw_argv": raw_argv,
        "starttime": start_before,
        "target": target,
    }


def snapshot_changes(
    initial: dict[str, object],
    final: dict[str, object],
) -> list[str]:
    return sorted(
        key
        for key in set(initial) | set(final)
        if initial.get(key) != final.get(key)
    )


def snapshot_receipt(snapshot: dict[str, object]) -> dict[str, object]:
    return {
        "argv": snapshot["argv"],
        "cgroup": snapshot["cgroup"],
        "packet_argv_classes": snapshot["packet_argv_classes"],
        "parent": snapshot["parent"],
        "pid1": snapshot["pid1"],
        "raw_argv_hex": bytes(snapshot["raw_argv"]).hex(),
        "starttime": snapshot["starttime"],
        "target": snapshot["target"],
    }


def candidate_outer_changes(
    outer_observation: dict[str, object] | None,
    initial_snapshot: dict[str, object] | None,
) -> list[str]:
    if outer_observation is None or initial_snapshot is None:
        return ["missing"]
    return sorted(
        key
        for key in ("argv", "cgroup", "parent", "raw_argv", "starttime", "target")
        if outer_observation.get(key) != initial_snapshot.get(key)
    )


def candidate_outer_receipt(
    outer_observation: dict[str, object],
) -> dict[str, object]:
    return {
        "argv": outer_observation["argv"],
        "cgroup": outer_observation["cgroup"],
        "parent": outer_observation["parent"],
        "outer_owner_relation": outer_observation["outer_owner_relation"],
        "raw_argv_hex": bytes(outer_observation["raw_argv"]).hex(),
        "starttime": outer_observation["starttime"],
        "target": outer_observation["target"],
    }


def ordinary_disposition(
    *,
    candidate_signal: bool,
    final_snapshot: dict[str, object] | None,
    outer_argv: list[str],
    outer_ppid: int,
    executable: str | None,
    cwd: str | None,
    executable_failure: dict[str, object] | None,
    cwd_failure: dict[str, object] | None,
) -> dict[str, object]:
    disposition_errors: list[str] = []
    read_failures = [
        failure
        for failure in (executable_failure, cwd_failure)
        if failure is not None
    ]
    authoritative_argv: list[str] | None = None
    authoritative_ppid: int | None = None
    if candidate_signal:
        if final_snapshot is None:
            disposition_errors.append("candidate final snapshot unavailable")
        else:
            snapshot_argv = final_snapshot.get("argv")
            snapshot_target = final_snapshot.get("target")
            if not isinstance(snapshot_argv, list) or not all(
                isinstance(token, str) for token in snapshot_argv
            ):
                disposition_errors.append("candidate final argv unavailable")
            else:
                authoritative_argv = list(snapshot_argv)
            if not isinstance(snapshot_target, dict) or not isinstance(
                snapshot_target.get("ppid"), int
            ):
                disposition_errors.append("candidate final PPid unavailable")
            else:
                authoritative_ppid = int(snapshot_target["ppid"])
    else:
        authoritative_argv = list(outer_argv)
        authoritative_ppid = outer_ppid
    matched_classes: list[str] = []
    if not disposition_errors and not read_failures:
        if executable is None or cwd is None:
            disposition_errors.append(
                "readlink completed without a value, failure, or disappearance"
            )
        elif authoritative_argv is not None:
            matched_classes = classes(authoritative_argv, executable, cwd)
    return {
        "argv": authoritative_argv,
        "classes": matched_classes,
        "errors": disposition_errors,
        "ppid": authoritative_ppid,
        "read_failures": read_failures,
    }


def is_permission_denied(
    read_failure: dict[str, object] | None,
    *,
    expected_stage: str,
) -> bool:
    return bool(
        read_failure
        and read_failure.get("type") == "PermissionError"
        and read_failure.get("errno") == 13
        and read_failure.get("stage") == expected_stage
    )


def systemd_pam_tuple_matches(
    *,
    snapshot: dict[str, object] | None,
    effective_uid: int,
    effective_gid: int,
) -> bool:
    expected_cgroup = (
        f"0::/user.slice/user-{effective_uid}.slice/"
        f"user@{effective_uid}.service/init.scope"
    )
    if not snapshot:
        return False
    raw_argv = snapshot.get("raw_argv")
    argv = snapshot.get("argv")
    target = snapshot.get("target")
    cgroup = snapshot.get("cgroup")
    parent = snapshot.get("parent")
    pid1 = snapshot.get("pid1")
    return bool(
        isinstance(target, dict)
        and isinstance(parent, dict)
        and isinstance(pid1, dict)
        and target.get("name") == "(sd-pam)"
        and raw_argv == b"(sd-pam)\0"
        and argv == ["(sd-pam)"]
        and target.get("uids") == [effective_uid] * 4
        and target.get("gids") == [effective_gid] * 4
        and target.get("cap_eff") == 0
        and target.get("cap_prm") == 0
        and target.get("cap_amb") == 0
        and target.get("tracer_pid") == 0
        and target.get("core_dumping") == 0
        and target.get("no_new_privs") == 0
        and target.get("seccomp") == 0
        and target.get("seccomp_filters") == 0
        and cgroup == expected_cgroup
        and target.get("ppid") == parent.get("pid")
        and parent.get("name") == "systemd"
        and parent.get("uids") == [effective_uid] * 4
        and parent.get("ppid") == pid1.get("pid") == 1
        and pid1.get("name") == "systemd"
        and pid1.get("uids") == [0] * 4
        and pid1.get("ppid") == 0
    )


def systemd_pam_exclusion(
    *,
    outer_observation: dict[str, object] | None,
    initial_snapshot: dict[str, object] | None,
    final_snapshot: dict[str, object] | None,
    effective_uid: int,
    effective_gid: int,
    executable_failure: dict[str, object] | None,
    cwd_failure: dict[str, object] | None,
    recovered_transition_valid: bool,
) -> bool:
    return bool(
        recovered_transition_valid
        and initial_snapshot
        and final_snapshot
        and not candidate_outer_changes(outer_observation, initial_snapshot)
        and not snapshot_changes(initial_snapshot, final_snapshot)
        and not initial_snapshot.get("packet_argv_classes")
        and not final_snapshot.get("packet_argv_classes")
        and is_permission_denied(
            executable_failure,
            expected_stage="executable",
        )
        and is_permission_denied(cwd_failure, expected_stage="cwd")
        and systemd_pam_tuple_matches(
            snapshot=final_snapshot,
            effective_uid=effective_uid,
            effective_gid=effective_gid,
        )
    )


def failures_before_cwd_disappearance(
    executable_failure: dict[str, object] | None,
    *,
    cwd_vanished: bool,
) -> list[dict[str, object]]:
    if cwd_vanished and executable_failure is not None:
        return [executable_failure]
    return []


def finish_empty_composite(
    errors: list[dict[str, object]],
    *,
    pid: int,
    label: str,
    stat_before: dict[str, object],
    status_record: dict[str, object],
    cmdline_record: dict[str, object],
    outer_pid: int,
    outer_starttime: int,
    inspector_generations: set[tuple[int, int]],
) -> dict[str, object] | None:
    cgroup, _ = read_cgroup_record(
        errors,
        pid=pid,
        stage=f"{label}-cgroup",
    )
    ancestry = capture_ancestry(
        errors,
        start_pid=int(status_record["ppid"]),
        label=f"{label}-target",
    )
    stat_after, _ = read_stat_record(
        errors,
        pid=pid,
        stage=f"{label}-stat-after",
    )
    if cgroup is None or ancestry is None or stat_after is None:
        return None
    try:
        validate_stat_identity_sandwich(stat_before, stat_after)
        validate_stat_status_pair(stat_before, status_record)
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=f"{label}-identity",
            detail=f"{type(exc).__name__}: {exc}",
        )
        return None
    append_state_errors(
        errors,
        pid=pid,
        stage=f"{label}-state",
        stat_state=str(stat_before["state"]),
        status_state=str(status_record["state"]),
        stat_after_state=str(stat_after["state"]),
    )
    owner_relation, owner_index = ancestry_contains_generation(
        ancestry,
        pid=outer_pid,
        starttime=outer_starttime,
    )
    inspector_relation = (
        int(stat_before["pid"]),
        int(stat_before["starttime"]),
    ) in inspector_generations
    parent_status = ancestry[0]["status"]
    if not isinstance(parent_status, dict):
        append_error(
            errors,
            pid=pid,
            stage=f"{label}-parent-relation",
            detail="parent status receipt was incomplete",
        )
        return None
    parent = {
        "name": parent_status["name"],
        "pid": ancestry[0]["pid"],
        "ppid": parent_status["ppid"],
        "uids": parent_status["uids"],
    }
    return {
        "ancestry": ancestry_identity(ancestry),
        "argv": list(cmdline_record["argv"]),
        "cgroup": cgroup,
        "outer_owner_relation": {
            "index": owner_index,
            "inspector": inspector_relation,
            "owned": owner_relation,
            "pid1_complete": bool(ancestry and ancestry[-1]["pid"] == 1),
        },
        "parent": parent,
        "raw_argv": bytes(cmdline_record["raw_argv"]),
        "stat_after": stat_after,
        "stat_before": stat_before,
        "status": status_record,
    }


def read_final_empty_composite(
    errors: list[dict[str, object]],
    *,
    pid: int,
    outer_pid: int,
    outer_starttime: int,
    inspector_generations: set[tuple[int, int]],
) -> dict[str, object]:
    before, absent = read_stat_record(
        errors,
        pid=pid,
        stage="empty-final-stat-before",
        allow_absent=True,
    )
    if absent:
        return {"kind": "absent"}
    if before is None:
        return {"kind": "incomplete"}
    status_record, _ = read_status_record(
        errors,
        pid=pid,
        stage="empty-final-status",
    )
    cmdline_record, _ = read_cmdline_record(
        errors,
        pid=pid,
        stage="empty-final-cmdline",
    )
    if status_record is None or cmdline_record is None:
        return {"kind": "incomplete"}
    composite = finish_empty_composite(
        errors,
        pid=pid,
        label="empty-final",
        stat_before=before,
        status_record=status_record,
        cmdline_record=cmdline_record,
        outer_pid=outer_pid,
        outer_starttime=outer_starttime,
        inspector_generations=inspector_generations,
    )
    if composite is None:
        return {"kind": "incomplete"}
    return {"composite": composite, "kind": "present"}


def validate_composite_transition(
    initial: dict[str, object],
    final: dict[str, object],
) -> None:
    initial_before = initial["stat_before"]
    initial_after = initial["stat_after"]
    final_before = final["stat_before"]
    final_after = final["stat_after"]
    initial_status = initial["status"]
    final_status = final["status"]
    initial_cgroup = initial["cgroup"]
    final_cgroup = final["cgroup"]
    validate_owner_relation_receipt(initial["outer_owner_relation"])
    validate_owner_relation_receipt(final["outer_owner_relation"])
    if (
        not isinstance(initial_before, dict)
        or not isinstance(initial_after, dict)
        or not isinstance(final_before, dict)
        or not isinstance(final_after, dict)
    ):
        raise ProtocolFault("composite stat receipt was missing")
    if not isinstance(initial_status, dict) or not isinstance(final_status, dict):
        raise ProtocolFault("composite status receipt was missing")
    for key in ("pid", "starttime", "ppid", "pgrp", "session"):
        if initial_before[key] != final_before[key]:
            raise ProtocolFault(f"final composite changed {key}")
    for key in ("pid", "tgid", "ppid", "uids"):
        if initial_status[key] != final_status[key]:
            raise ProtocolFault(f"final status changed {key}")
    if initial_cgroup != final_cgroup:
        raise ProtocolFault("final cgroup changed")
    if initial["ancestry"] != final["ancestry"]:
        raise ProtocolFault("final ancestry changed")
    if initial["outer_owner_relation"] != final["outer_owner_relation"]:
        raise ProtocolFault("final outer-owner relation changed")
    if (
        initial_before["state"] not in STAT_NONTERMINAL_STATES
        or initial_after["state"] not in STAT_NONTERMINAL_STATES
        or final_before["state"] not in STAT_NONTERMINAL_STATES
        or final_after["state"] not in STAT_NONTERMINAL_STATES
        or initial_status["state"] not in STATUS_NONTERMINAL_STATES
        or final_status["state"] not in STATUS_NONTERMINAL_STATES
    ):
        raise ProtocolFault("composite transition contained terminal State")


def validate_owner_relation_receipt(relation: object) -> None:
    if not isinstance(relation, dict):
        raise ProtocolFault("outer-owner relation receipt was incomplete")
    required = ("index", "inspector", "owned", "pid1_complete")
    if any(key not in relation for key in required):
        raise ProtocolFault("outer-owner relation receipt was incomplete")
    if not isinstance(relation["inspector"], bool) or not isinstance(relation["owned"], bool):
        raise ProtocolFault("outer-owner relation receipt was malformed")
    if relation["index"] is not None and not isinstance(relation["index"], int):
        raise ProtocolFault("outer-owner relation index was malformed")
    if relation["pid1_complete"] is not True:
        raise ProtocolFault("outer-owner ancestry was not PID-1 complete")

def deterministic_readlink_receipt(
    *,
    reached: bool,
    value: str | None,
    read_failure: dict[str, object] | None,
    disappeared: bool,
) -> dict[str, object]:
    if not reached:
        if value is not None or read_failure is not None or disappeared:
            raise ProtocolFault("unreached readlink carried outcome evidence")
        return {
            "detail": None,
            "disappeared": False,
            "errno": None,
            "failure": None,
            "reached": False,
            "stage": None,
            "type": None,
            "value": None,
        }
    populated = int(value is not None) + int(read_failure is not None) + int(disappeared)
    if populated != 1:
        raise ProtocolFault("reached readlink did not have exactly one outcome")
    return {
        "detail": (
            str(read_failure.get("error"))
            if read_failure is not None
            else ("process generation disappeared" if disappeared else None)
        ),
        "disappeared": disappeared,
        "errno": read_failure.get("errno") if read_failure is not None else None,
        "failure": dict(read_failure) if read_failure is not None else None,
        "reached": True,
        "stage": read_failure.get("stage") if read_failure is not None else None,
        "type": read_failure.get("type") if read_failure is not None else None,
        "value": value,
    }

def evaluate_readable_process(
    errors: list[dict[str, object]],
    excluded_entries: list[dict[str, object]],
    matches: list[dict[str, object]],
    *,
    pid: int,
    status_record: dict[str, object],
    stat_starttime: int,
    raw_argv: bytes,
    argv: list[str],
    owned_wrapper: bool,
    effective_uid: int,
    effective_gid: int,
    recovered_composite: dict[str, object] | None = None,
    recovered_transition_valid: bool = True,
) -> dict[str, object]:
    entry = PROC / str(pid)
    candidate_signal = pam_candidate_signal(
        status_record=status_record,
        raw_argv=raw_argv,
        argv=argv,
    )
    outer_candidate_target: dict[str, object] | None = None
    if candidate_signal:
        try:
            outer_candidate_target = candidate_status(
                status_record["values"]  # type: ignore[arg-type]
            )
        except Exception as exc:
            append_error(
                errors,
                pid=pid,
                stage="systemd-pam-outer-target",
                detail=f"{type(exc).__name__}: {exc}",
            )
    initial_snapshot = (
        read_candidate_snapshot(errors, pid=pid, label="initial")
        if candidate_signal
        else None
    )
    outer_observation = None
    if candidate_signal and outer_candidate_target is not None:
        outer_observation = {
            "argv": argv,
            "cgroup": (
                str(recovered_composite["cgroup"]["raw"]).rstrip("\n")  # type: ignore[index]
                if recovered_composite is not None
                else (initial_snapshot or {}).get("cgroup")
            ),
            "outer_owner_relation": (
                recovered_composite["outer_owner_relation"]
                if recovered_composite is not None
                else {
                    "index": None,
                    "inspector": False,
                    "owned": owned_wrapper,
                    "pid1_complete": True,
                }
            ),
            "parent": (
                recovered_composite["parent"]
                if recovered_composite is not None
                else (initial_snapshot or {}).get("parent")
            ),
            "raw_argv": raw_argv,
            "starttime": stat_starttime,
            "target": outer_candidate_target,
        }
    if candidate_signal:
        outer_changes = candidate_outer_changes(
            outer_observation,
            initial_snapshot,
        )
        if outer_changes:
            append_error(
                errors,
                pid=pid,
                stage="systemd-pam-outer-revalidation",
                detail=(
                    "outer candidate observation changed before the pinned "
                    f"initial snapshot: {','.join(outer_changes)}"
                ),
            )
    executable, executable_failure, executable_vanished = readlink_result(
        entry,
        pid=pid,
        stage="exe",
    )
    if executable_failure is not None:
        executable_failure["stage"] = "executable"
    if executable_vanished:
        append_error(
            errors,
            pid=pid,
            stage="executable-disappearance",
            detail="readable process disappeared during executable read",
        )
        return deterministic_readable_evaluation_receipt(
            executable=deterministic_readlink_receipt(
                reached=True,
                value=None,
                read_failure=None,
                disappeared=True,
            ),
            cwd=deterministic_readlink_receipt(
                reached=False,
                value=None,
                read_failure=None,
                disappeared=False,
            ),
            outcome="error:executable-disappearance",
            disposition=None,
        )
    cwd, cwd_failure, cwd_vanished = readlink_result(
        entry,
        pid=pid,
        stage="cwd",
    )
    if cwd_vanished:
        for prior_failure in failures_before_cwd_disappearance(
            executable_failure,
            cwd_vanished=True,
        ):
            append_failure(errors, pid=pid, read_failure=prior_failure)
        append_error(
            errors,
            pid=pid,
            stage="cwd-disappearance",
            detail="readable process disappeared during cwd read",
        )
        return deterministic_readable_evaluation_receipt(
            executable=deterministic_readlink_receipt(
                reached=True,
                value=executable,
                read_failure=executable_failure,
                disappeared=False,
            ),
            cwd=deterministic_readlink_receipt(
                reached=True,
                value=None,
                read_failure=None,
                disappeared=True,
            ),
            outcome="error:cwd-disappearance",
            disposition=None,
        )
    final_snapshot = (
        read_candidate_snapshot(errors, pid=pid, label="final")
        if candidate_signal
        else None
    )
    if initial_snapshot is not None and final_snapshot is not None:
        changed_fields = snapshot_changes(initial_snapshot, final_snapshot)
        if changed_fields:
            append_error(
                errors,
                pid=pid,
                stage="systemd-pam-revalidation",
                detail=f"candidate snapshot changed: {','.join(changed_fields)}",
            )
    if owned_wrapper:
        append_error(
            errors,
            pid=pid,
            stage="owned-wrapper-descendant",
            detail="candidate is a non-inspector descendant of recorded outer owner",
        )
    if (
        not owned_wrapper
        and systemd_pam_exclusion(
            outer_observation=outer_observation,
            initial_snapshot=initial_snapshot,
            final_snapshot=final_snapshot,
            effective_uid=effective_uid,
            effective_gid=effective_gid,
            executable_failure=executable_failure,
            cwd_failure=cwd_failure,
            recovered_transition_valid=recovered_transition_valid,
        )
    ):
        excluded_entries.append(
            {
                "class": "systemd-pam-session-helper",
                "cwd_denial": cwd_failure,
                "effective_gid": effective_gid,
                "effective_uid": effective_uid,
                "executable_denial": executable_failure,
                "final_snapshot": snapshot_receipt(final_snapshot or {}),
                "initial_snapshot": snapshot_receipt(initial_snapshot or {}),
                "outer_observation": candidate_outer_receipt(
                    outer_observation or {}
                ),
                "pid": pid,
            }
        )
        return deterministic_readable_evaluation_receipt(
            executable=deterministic_readlink_receipt(
                reached=True,
                value=executable,
                read_failure=executable_failure,
                disappeared=False,
            ),
            cwd=deterministic_readlink_receipt(
                reached=True,
                value=cwd,
                read_failure=cwd_failure,
                disappeared=False,
            ),
            outcome="excluded:systemd-pam",
            disposition=None,
        )
    disposition = ordinary_disposition(
        candidate_signal=candidate_signal,
        final_snapshot=final_snapshot,
        outer_argv=argv,
        outer_ppid=int(status_record["ppid"]),
        executable=executable,
        cwd=cwd,
        executable_failure=executable_failure,
        cwd_failure=cwd_failure,
    )
    for read_failure in disposition["read_failures"]:
        append_failure(
            errors,
            pid=pid,
            read_failure=read_failure,
        )
    for disposition_error in disposition["errors"]:
        append_error(
            errors,
            pid=pid,
            stage="ordinary-disposition",
            detail=str(disposition_error),
        )
    for process_class in disposition["classes"]:
        matches.append(
            {
                "argv": disposition["argv"],
                "class": process_class,
                "cwd": cwd,
                "executable": executable,
                "pid": pid,
                "ppid": disposition["ppid"],
            }
        )
    outcome = (
        "match"
        if disposition["classes"]
        else (
            "error"
            if disposition["errors"] or disposition["read_failures"]
            else "no-match"
        )
    )
    return deterministic_readable_evaluation_receipt(
        executable=deterministic_readlink_receipt(
            reached=True,
            value=executable,
            read_failure=executable_failure,
            disappeared=False,
        ),
        cwd=deterministic_readlink_receipt(
            reached=True,
            value=cwd,
            read_failure=cwd_failure,
            disappeared=False,
        ),
        outcome=outcome,
        disposition=disposition,
    )

def validate_initial_authority(
    *,
    preliminary_status: dict[str, object] | None,
    stat_before: dict[str, object] | None,
    complete_status: dict[str, object] | None,
    cmdline_record: dict[str, object] | None,
    empty_final_calls: int = 0,
    require_nonempty: bool = True,
) -> tuple[dict[str, object], list[str]]:
    if preliminary_status is None:
        raise ProtocolFault("preliminary-status failure")
    if stat_before is None:
        raise ProtocolFault("stat-before failure")
    if complete_status is None:
        raise ProtocolFault("complete-status failure")
    if cmdline_record is None:
        raise ProtocolFault("cmdline failure")
    validate_status_transition(preliminary_status, complete_status)
    validate_stat_status_pair(stat_before, complete_status)
    raw_value = cmdline_record.get("raw_argv")
    argv_value = cmdline_record.get("argv")
    if not isinstance(raw_value, bytes):
        raise ProtocolFault("cmdline raw receipt was missing")
    if not isinstance(argv_value, list) or not all(
        isinstance(token, str) for token in argv_value
    ):
        raise ProtocolFault("cmdline decoded receipt was missing")
    if decode_cmdline(raw_value) != argv_value:
        raise ProtocolFault("cmdline raw/decoded contradiction")
    if require_nonempty and (not raw_value or not argv_value):
        raise ProtocolFault("initial authority was not nonempty")
    if empty_final_calls != 0:
        raise ProtocolFault("nonempty authority invoked empty-final helper")
    return complete_status, list(argv_value)

def pure_validate_ancestry(nodes: list[dict[str, object]], start_pid: int) -> None:
    if not nodes:
        raise ProtocolFault("ancestry was empty")
    current = start_pid
    captured: set[int] = set()
    for node in nodes:
        identity = generation_node_identity(node)
        before = node["stat_before"]
        after = node["stat_after"]
        status_record = node["status"]
        if not isinstance(before, dict) or not isinstance(after, dict) or not isinstance(status_record, dict):
            raise ProtocolFault("ancestry node receipt was incomplete")
        validate_stat_identity_sandwich(before, after)
        validate_stat_status_pair(before, status_record)
        if state_errors(
            stat_state=str(before["state"]),
            status_state=str(status_record["state"]),
            stat_after_state=str(after["state"]),
        ):
            raise ProtocolFault("terminal ancestry State")
        pid = int(node["pid"])
        if pid != current:
            raise ProtocolFault("ancestry PID relation was incomplete")
        if pid in captured:
            raise ProtocolFault("ancestry cycle")
        captured.add(pid)
        if pid == 1:
            if int(node["ppid"]) != 0:
                raise ProtocolFault("PID 1 had nonzero PPid")
            return
        parent = int(node["ppid"])
        if parent <= 0:
            raise ProtocolFault("premature PPid 0")
        current = parent
    raise ProtocolFault("ancestry ended without PID 1")

def exact_control_fault(
    name: str,
    expected_fragment: str,
    thunk: Callable[[], object],
) -> str:
    try:
        thunk()
    except ProtocolFault as exc:
        if expected_fragment not in str(exc):
            raise ProtocolFault(
                f"{name} reached wrong failure: expected {expected_fragment!r}, "
                f"observed {str(exc)!r}"
            ) from exc
        return f"error:{name}"
    raise ProtocolFault(f"{name} did not reach its required failure")


def require_control_condition(name: str, condition: bool, detail: str) -> str:
    if not condition:
        raise ProtocolFault(f"{name} did not prove {detail}")
    return f"error:{name}"

def composite_terminal_errors(composite: dict[str, object]) -> list[str]:
    validate_composite_required_receipts(composite)
    stat_record = composite.get("stat_before")
    stat_after = composite.get("stat_after")
    status_record = composite.get("status")
    if (
        not isinstance(stat_record, dict)
        or not isinstance(stat_after, dict)
        or not isinstance(status_record, dict)
    ):
        raise ProtocolFault("composite terminal receipt was incomplete")
    return state_errors(
        stat_state=str(stat_record["state"]),
        status_state=str(status_record["state"]),
        stat_after_state=str(stat_after["state"]),
    )


def validate_composite_required_receipts(composite: dict[str, object]) -> None:
    required_types: dict[str, type] = {
        "ancestry": list,
        "argv": list,
        "cgroup": dict,
        "outer_owner_relation": dict,
        "parent": dict,
        "raw_argv": bytes,
        "stat_after": dict,
        "stat_before": dict,
        "status": dict,
    }
    for key, expected_type in required_types.items():
        if not isinstance(composite.get(key), expected_type):
            raise ProtocolFault(f"composite {key} receipt was incomplete")
    validate_owner_relation_receipt(composite["outer_owner_relation"])
    if decode_cmdline(composite["raw_argv"]) != composite["argv"]:  # type: ignore[arg-type]
        raise ProtocolFault("cmdline raw/decoded contradiction")


def assess_empty_transition(
    *,
    initial: dict[str, object],
    final_kind: str,
    final: dict[str, object] | None,
    prior_failure: bool,
) -> dict[str, object]:
    validate_composite_required_receipts(initial)
    initial_terminal = composite_terminal_errors(initial)
    if initial_terminal:
        return {
            "error": "initial-terminal-present",
            "transition": "empty-to-terminal-present",
            "valid": False,
        }
    if final_kind == "absent":
        return {
            "error": "prior-failure-before-disappearance" if prior_failure else None,
            "transition": "empty-to-incomplete" if prior_failure else "empty-to-disappeared",
            "valid": not prior_failure,
        }
    if final_kind != "present" or final is None:
        return {
            "error": "final-composite-incomplete",
            "transition": "empty-to-incomplete",
            "valid": False,
        }
    validate_composite_required_receipts(final)
    final_terminal = composite_terminal_errors(final)
    if final_terminal:
        return {
            "error": "final-terminal-present",
            "transition": "empty-to-terminal-present",
            "valid": False,
        }
    if prior_failure:
        return {
            "error": "candidate-local-error-before-final-disposition",
            "transition": "empty-to-incomplete",
            "valid": False,
        }
    try:
        validate_composite_transition(initial, final)
    except ProtocolFault as exc:
        return {
            "error": str(exc),
            "transition": "empty-to-reused-or-changed",
            "valid": False,
        }
    raw_argv = final.get("raw_argv")
    argv = final.get("argv")
    if not isinstance(raw_argv, bytes) or not isinstance(argv, list):
        return {
            "error": "final-argv-receipt-incomplete",
            "transition": "empty-to-incomplete",
            "valid": False,
        }
    if not raw_argv or not argv:
        return {
            "error": "argv-empty-stable",
            "transition": "empty-to-persistent-empty",
            "valid": False,
        }
    return {"error": None, "transition": "empty-to-readable", "valid": True}


def recovered_candidate_gate(
    *,
    initial: dict[str, object],
    final_kind: str,
    final: dict[str, object] | None,
    candidate_local_error_stages: tuple[str, ...],
) -> dict[str, object]:
    assessment = assess_empty_transition(
        initial=initial,
        final_kind=final_kind,
        final=final,
        prior_failure=bool(candidate_local_error_stages),
    )
    readable = bool(
        final_kind == "present"
        and final is not None
        and final.get("raw_argv")
        and final.get("argv")
    )
    eligible = bool(
        assessment["valid"]
        and readable
        and not candidate_local_error_stages
    )
    return {
        "assessment": assessment,
        "candidate_local_error_stages": list(candidate_local_error_stages),
        "pam_evaluation_allowed": eligible,
        "readlink_evaluation_allowed": eligible,
        "recovered_evaluation_allowed": eligible,
    }


def dispatch_recovered_candidate(
    *,
    gate: dict[str, object],
    evaluator: Callable[[], dict[str, object]],
) -> dict[str, object]:
    receipt: dict[str, object] = {
        "evaluation_receipt": None,
        "pam_evaluation_authorizations": 0,
        "readlink_evaluation_calls": 0,
        "recovered_evaluator_calls": 0,
    }
    if not gate.get("recovered_evaluation_allowed"):
        return receipt
    if not (
        gate.get("readlink_evaluation_allowed")
        and gate.get("pam_evaluation_allowed")
    ):
        raise ProtocolFault("recovered gate authorities were contradictory")
    receipt["readlink_evaluation_calls"] = 1
    receipt["pam_evaluation_authorizations"] = 1
    receipt["recovered_evaluator_calls"] = 1
    receipt["evaluation_receipt"] = evaluator()
    return receipt

def pure_recovered_disposition(
    *,
    initial: dict[str, object],
    final: dict[str, object],
    executable: str = "/usr/bin/control",
    cwd: str = APP_ROOT,

        initial=initial,
        final_kind="present",
        final=final,
        candidate_local_error_stages=(),
    )
    assessment = gate["assessment"]
    if not isinstance(assessment, dict):
        raise ProtocolFault("recovered gate assessment was incomplete")
    if not gate["recovered_evaluation_allowed"]:
        return f"error:{assessment['error']}"
    status_record = final["status"]
    relation = final["outer_owner_relation"]
    if not isinstance(status_record, dict) or not isinstance(relation, dict):
        raise ProtocolFault("recovered disposition receipt was incomplete")
    disposition = ordinary_disposition(
        candidate_signal=False,
        final_snapshot=None,
        outer_argv=list(final["argv"]),
        outer_ppid=int(status_record["ppid"]),
        executable=executable,
        cwd=cwd,
        executable_failure=None,
        cwd_failure=None,
    )
    classes_found = list(disposition["classes"])
    prefix = "error+" if relation.get("owned") else ""
    if classes_found:
        return prefix + "match:" + ",".join(classes_found)
    return "error:owned-wrapper-descendant" if prefix else "no-match"

def expected_control_disposition(name: str) -> str:
    if name.startswith("c0") and "-empty-final-" in name:
        return f"match:{name.split('-empty-final-', 1)[1]}"
    if name == "c09-readable-unrelated":
        return "no-match"
    if name == "c09-readable-unrelated-receipt":
        return "clean-readlink-receipt"
    if name == "c10-confirmed-disappearance":
        return "confirmed-disappearance"
    if name.startswith("c12-"):
        return "argv-empty-stable"
    if name.startswith("c18-owned-"):
        return f"error+match:{name.split('c18-owned-', 1)[1]}"
    if name.startswith("c20-final-authoritative-"):
        return f"match:{name.split('c20-final-authoritative-', 1)[1]}"
    if name == "c21-pam-positive" or name == "c65-nonempty-clean-pam":
        return "excluded:systemd-pam"
    if name == "c16-env-positive":
        return "clean"
    if name.startswith("c65-nonempty-clean-"):
        suffix = name.split("c65-nonempty-clean-", 1)[1]
        return "no-match" if suffix == "unrelated" else f"match:{suffix}"
    return f"error:{name}"

def invalid_state_value(kind: str) -> str:
    if kind == "empty":
        return ""
    if kind == "multi":
        return "SS"
    if kind == "unknown":
        return "Q"
    raise ProtocolFault(f"no value exists for missing State kind {kind}")


def parse_located_state_record(
    *,
    location: str,
    parser: str,
    text: str,
    expected_pid: int,
) -> dict[str, object]:
    if location not in {"initial", "final"}:
        raise ProtocolFault(f"invalid State-control location {location}")
    try:
        if parser == "stat":
            return parse_stat_text(text, expected_pid=expected_pid)
        if parser == "status":
            return parse_status_text(text, expected_pid=expected_pid)
        raise ProtocolFault(f"invalid State-control parser {parser}")
    except ProtocolFault as exc:
        raise ProtocolFault(f"{location} {parser} State record: {exc}") from exc

            "receipt was incomplete",

        )
    raise ProtocolFault(f"unrecognized Control 15 name {name}")

        )

        name,

            if kind == "missing"

            return "excluded:systemd-pam" if excluded else "wrong:not-excluded"
        found = classes(actual_argv, "/usr/bin/control", APP_ROOT)
        if suffix == "unrelated":
            return "no-match" if not found else f"wrong:{','.join(found)}"
        return f"match:{suffix}" if suffix in found else f"wrong:{','.join(found)}"
    if name.startswith("c66-nonempty-"):
        shape = name.split("-")[2]
        if shape == "packet":
            argv = list(PACKET_CONTROL_ARGV["hosted-smoke"])
        elif shape == "unrelated":
            argv = ["unrelated"]
        elif shape == "pam":
            argv = ["(sd-pam)"]
            preliminary = synthetic_candidate_status_text(ppid=602)
            stat_before = synthetic_stat_text(ppid=602)
            complete = synthetic_candidate_status_text(ppid=602)
        else:
            raise ProtocolFault(f"unrecognized nonempty process shape {shape}")
    if name == "c66-nonempty-pam-fallback":
        return exact_control_fault(
            name,
            "nonempty authority invoked empty-final helper",
            lambda: validate_initial_authority(
                preliminary_status=parse_status_text(preliminary, expected_pid=700),
                stat_before=parse_stat_text(stat_before, expected_pid=700),
                complete_status=parse_status_text(complete, expected_pid=700),
                cmdline_record=decode_cmdline_receipt(raw_control_argv(["(sd-pam)"])),
                empty_final_calls=1,
            ),
        )
    if name == "c66-nonempty-pam-starttime-mismatch":
        _target, _parent, snapshot, outer = positive_pam_control()
        outer = {**outer, "starttime": 123455}
        return require_control_condition(
            name,
            "starttime" in candidate_outer_changes(outer, snapshot),
            "PAM nonempty starttime mismatch",
        )
    if name == "c66-nonempty-pam-outer-mismatch":
        _target, _parent, snapshot, outer = positive_pam_control()
        outer = {**outer, "argv": ["changed"], "raw_argv": b"changed\0"}
        return require_control_condition(
            name,
            set(candidate_outer_changes(outer, snapshot)) == {"argv", "raw_argv"},
            "PAM nonempty outer observation mismatch",
        )
    parts = name.split("-")
    stage = "-".join(parts[3:])
    if stage == "preliminary-status":
        fragment = "preliminary-status failure"
        preliminary = None  # type: ignore[assignment]
    elif stage == "stat-before":
        fragment = "stat-before failure"
        stat_before = None  # type: ignore[assignment]
    elif stage == "status-contradiction":
        fragment = "status transition changed ppid"
        complete = synthetic_status_text(ppid=601)
    elif stage == "complete-status":
        fragment = "complete-status failure"
        complete = None  # type: ignore[assignment]
    elif stage == "cmdline":
        fragment = "cmdline failure"
        raw_argv: bytes | None = None
    else:
        raise ProtocolFault(f"unrecognized nonempty authority stage {stage}")
    if stage != "cmdline":
        raw_argv = raw_control_argv(argv)
    return exact_control_fault(
        name,
        fragment,
        lambda: validate_initial_authority(
            preliminary_status=(
                parse_status_text(preliminary, expected_pid=700)
                if preliminary is not None
                else None
            ),
            stat_before=(
                parse_stat_text(stat_before, expected_pid=700)
                if stat_before is not None
                else None
            ),
            complete_status=(
                parse_status_text(complete, expected_pid=700)
                if complete is not None
                else None
            ),
            cmdline_record=(
                decode_cmdline_receipt(raw_argv)
                if raw_argv is not None
                else None
            ),
        ),
    )

def run_protocol_controls(
    errors: list[dict[str, object]],
) -> dict[str, object]:
    results: list[dict[str, str]] = []
    observed_names: list[str] = []
    for name in FROZEN_CONTROL_NAMES:
        expected = expected_control_disposition(name)
        try:
            actual = control_actual(name)
        except Exception as exc:
            actual = f"control-fault:{type(exc).__name__}:{exc}"
        observed_names.append(name)
        results.append(
            {
                "actual": actual,
                "expected": expected,
                "name": name,
            }
        )
        if actual != expected:
            append_error(
                errors,
                pid=0,
                stage=f"protocol-control-{name}",
                detail=f"expected {expected}, observed {actual}",
            )
    if len(observed_names) != len(set(observed_names)):
        append_error(
            errors,
            pid=0,
            stage="protocol-control-manifest",
            detail="control results contained duplicate names",
        )
    if tuple(sorted(observed_names)) != FROZEN_CONTROL_NAMES:
        append_error(
            errors,
            pid=0,
            stage="protocol-control-manifest",
            detail="control result names did not match the frozen manifest",
        )
    return {
        "count": len(FROZEN_CONTROL_NAMES),
        "names": list(FROZEN_CONTROL_NAMES),
        "results": results,
    }


def append_validation_failure(
    errors: list[dict[str, object]],
    *,
    pid: int,
    stage: str,
    thunk: Callable[[], object],
) -> bool:
    try:
        thunk()
    except Exception as exc:
        append_error(
            errors,
            pid=pid,
            stage=stage,
            detail=f"{type(exc).__name__}: {exc}",
        )
        return False
    return True

            },
            ensure_ascii=True,
            separators=(",", ":"),
            sort_keys=True,
        )
    )
