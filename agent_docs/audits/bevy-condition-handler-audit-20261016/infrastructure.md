## Corrections established by crossing caller and processor boundaries

1. **DamageApplied remains ordinary mutable annotation dispatch.** Entity._complete_damage_applied_event (3583–3643) creates and advances it through ordinary Execution/Effect/Completion after HP commits. BodyResponseProcessor returns body_release; Concentrating returns concentration_broken. Those returned versions are accepted. An explicit committed-notification API uses isolated deep per-handler views and ignores replacements; the word “applied” does not choose that API. Later annotation cancellation does not undo committed HP.
2. **Cleanup owner is not automatically contribution gate.** BaseBlock registration does not fill contribution_owner_uuid. Concentrating installs its damage/death handler after the general provisional handle-binding pass, with no such gate. BaseCondition.contributions_active checks graph/suppression, not applied membership. Keep nullable gate ownership, provisional authority, cleanup and active membership distinct.
3. **Required hooks exceed EventHandler declarations.** Sensory pre-completion, restraint reconciliation, summoning admission/removal/settled/close, condition membership and owner placement, and forced-movement on_landing all require native concrete system exposure. Native component storage hooks cannot return admission/results or replace domain lifecycle stages.
4. **Accepted child result is not always a success prerequisite.** Shield and several condition actions ignore a child's admission Boolean while retaining costs and their own result. Duration callers sometimes return expiry/save success despite a vetoable removal. Preserve caller policy, rather than treating every awaited child as a transaction-wide success condition.
5. **Ambient execution data cannot remain global across yields.** Saving throws set current target, save context and lineage on live values, clear them after accepted completion, then return final outcome. Action batches temporarily change current target and restore it. Pending native requests need explicit invocation/application context and exact cleanup scope; merely releasing a Rust borrow does not remove that logical dependency.
6. **Publication order and source attribution are separate.** A synchronous global cursor slice currently identifies emitted work. Once roots/applications interleave, exact request IDs, causal ancestry and root membership must supply attribution. Retain global order for history and source-defined priority without misattributing unrelated work inside a suspended cursor interval.

## Native exposure and queue constraints

Use concrete native systems over typed components/resources for each actual processor family and lifecycle seam. Installed handler data retains stable domain identity, dispatch rank, trigger/policy, concrete processor registration and authored capture state. Selected invocation data retains its working event mode, cursor, required child/result and guard. Condition/grant data owns exact modifiers, resources, sources and graph links; the domain coordinators choose when those contributions become visible and when cleanup/publication settles.

Native typed input/output systems support synchronous accepted-result seams. Scheduled typed queue consumers support pending work and independent computation. Commands flushing is neither accepted-result propagation nor logical completion. The optional native system-instance reentry diagnostic proves only its stated seam; it is not a new universal gameplay dispatcher. No domain object hierarchy, reflection router, universal effect interpreter or second opaque world is required.

The static scanner cannot prove all transitive helper behavior, dynamic third-party extensions, rule correctness, queue liveness or parallel safety. This report closes ownership and boundary classification for the 409 indexed infrastructure rows, with those explicit limitations. It does not mark them all as complete-method behavioral review. Full source-supported native qualification still needs concrete condition/handler scenarios from the companion reports.
