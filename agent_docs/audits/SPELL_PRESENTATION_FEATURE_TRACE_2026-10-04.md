## Source import and measurement

`devtools/import_class_media.py` selects from the preserved accepted `roar-cast-v5` package, manifest SHA256 `d046dd3171ae1d85fe213490995ddaf140f9e1ce90be3d90db55ed159a96e2de`. It checks original bank/film hashes and uses the existing verified private/local installer. The accepted JavaScript palette rounding preserves source alpha.

It installed 61 VFX payloads and 210 **missing** original Idle2/Idle4 sheets, preserving existing installed sheets. Each of 105 categories was matched against its installed Idle family: 104 came from the original vendor archive and NakedBody from the preserved NeuroClient source. `class_media/source.json` records the archive path/hash and every category selection. `devtools/author_class_presentation.py` authors only the selected typed bindings and nine original preview icon paths; their 8×-coverage raster method is stated in `markers-source.json`, without claiming browser-pixel identity.

`devtools/measure_weapon_trails.py` applies the original alpha/distance algorithm to 135 actual weapon/clip sheets, 16,200 cells. All 120 original Melee1/Attack1 points match exactly. The runtime uses the original mesh/shader/palette equations, with the 2 px source grouping scaled by zoom/actor size and registered to the original source canvas. Four-camera vector conversion removes the projection's map-center translation before applying the actor offset.

The new head/face data measures 240 original Idle2/Idle4 cells. Special1 has 118 measured second-palm cells; two ambiguous cells stay null. The source hashes, method and nulls are explicit in `class_media/sockets-source.json`. Fixed sheets have no separable measured weapon layer: they retain their existing authored pose/slash and only receive an admitted contact burst. Their existing off-hand approximation remains disclosed. Unmeasured fixed-rig face/palm effects are omitted, not attached to a body bounding box.
