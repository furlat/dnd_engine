## What was reviewed

I viewed one relevant 15-sample, South-facing action strip at 2× scale on a neutral checkerboard for every one of the 100 identities, including every member of all four source families. Most are `Attack1`/`Attack 1`; the per-row exceptions are the undead archers’ `QuickShot`, two casters’ `CastSpell`, and the two prone Decay variants’ `Zombie melee 1`. Gallery tiles are numbered 001–100 in source roster order across twenty five-tile sheets (`gallery-001-005.png` through `gallery-096-100.png`). The per-row lookup is [attack_review_index.json](../../.runtime/pack-study-20260930/undead-enemy-completion/attack_review_index.json); the full gallery directory is `../../.runtime/pack-study-20260930/undead-enemy-completion/`. This is not all-direction/all-clip adjudication. The source archives lack clip FPS/contact metadata.

Attack labels are not interchangeable semantics. A baked slash, flash, or glow is visual art, not a separate native action or damage type. Each table below pairs a sampled animation observation with a conservative content proposal. Rows reuse original report flavor names and profile tags. “Native reuse” means a candidate existing rules composition, not an assertion that the source image proves it.

## Corrected native facts and evidence-led decisions

- Canonical `creature.skeleton_warrior` in `dnd/monsters/bestiary.py` equips armor scraps, longsword, wooden shield, and acid flask (builder around lines 660–690). The earlier S-LORD “shortsword” statement was wrong. The fixed 2DeathLord art’s shield and long blade are broadly compatible with the weapon/shield silhouette, but acid flask is a game-content fact not depicted by the sprite. Keep this independent from the deliberately modular `NakedBody2` warrior path.
- Canonical `creature.skeleton_archer` equips armor scraps, shortbow, two daggers, and Mark Target (`bestiary.py` around 710+; declared in `bestiary_content.py`). The fixed 5Archer/7DarkArcher bodies show a bow but not those daggers. Treat them as chassis evidence for an authored bow-only skeleton variant; omit daggers from that presentation unless a different body is selected. Mark Target remains optional native content, not an art-derived property.
- Enemy 2Shooter and 7Sniper show a long, shouldered firearm-like silhouette in `Attack1`; visible magenta/red-orange discharge pixels strengthen the ranged/firearm reading. Exact item model/rules remain unverified. Native code has no carried creature firearm; `environment.arcane_machine_gun` is an environmental device, not a substitute. The selected refinements propose a carried carbine and precision rifle; faithful implementation still needs native content and compatibility verification.
- All six HD Zombie Soldier rows show close-range arm/hand attacks in the reviewed `Attack1`; their uniform does not establish gun handling. The five top-down Zombie Soldier rows visibly shoulder and use firearm-like long objects. Their selected design uses proposed service long guns through the shared concept below, whose native support remains unverified.
- Top-down radioactive zombie strips contain green emissions and some shot-like particles. That establishes artwork only. Keep the native zombie melee baseline unless an authored ranged/radiation behavior is deliberately added. Likewise, Enemy caster/elemental glow and baked slash effects do not establish spells or damage types.
- For ordinary natural zombies, reuse existing `creature.zombie` melee slam and Undead Fortitude. Hulk art supports a larger/heavier *presentation*; extra stats/size/multiattack are a separate native content choice. Decay 01/04 can visually use low/prone attacks, but `Emerge` does not create surprise/ambush rules.

The practical proposal is to prefer the closest current native creature/item/behavior composition and explicitly preserve visible equipment. Where a source item cannot be matched to an existing carried item, the report marks the presentation gap rather than silently substituting equipment. “Elite” is always an optional additional content identity reusing the row kit with authored durability tuning; no special ability is inferred from art.

### Shared proposed carried long gun

The selected firearm concept is a two-handed carried long gun firing a
physical piercing projectile through the existing ranged weapon Attack
pipeline. Author a distinct project item definition with ranged/two-handed
properties; it is neither a crossbow nor the environmental spell device.
Shooter uses it as a mobile carbine, Sniper as a precision long rifle, and the
five Soldier variants as an undead service rifle. Those are role/loadout
proposals; the small source frames do not identify a real-world model.

Use the same passive weapon/ordinary attack composition where statistics
coincide. Rifle ranges, damage dice, proficiency and balance remain authored
parameters, as with the other unbalanced NPC proposals. Ammunition expenditure,
magazine capacity, reload costs and an aimed-shot rider are additional explicit
rule proposals if desired; none is established as implemented firearm support
by this study. A future item/action capability check must establish which
existing weapon owners can actually execute the selected definition before
these rows are described as playable. This completes their matching design
concept while retaining the honest native and presentation gaps.

Current native reuse proposal:

- `Z-DEAD`, `Z-SECURITY`, `Z-SOLDIER` (HD Soldier art), `Z-EMERGE`: existing Zombie body/action baseline; Undead Fortitude is reused only where the chosen native creature declares it. Costume does not add police, command, tool, or firearm inventory.
- `Z-BULK`: zombie baseline; do not substitute Ogre Zombie unless size, stats, and morningstar are intentionally authored. Hulk silhouette alone is insufficient.
- `Z-GLOW` / `Z-MUTANT`: zombie baseline. Green glow/malformed art remains presentation; no irradiation aura, acid, paralysis, or ghoul rule without explicit native composition.
- `S-LORD`: canonical Skeleton Warrior is the closest existing native candidate for long blade + shield and carries the real canonical gear above.
- `S-ARCHER`: author a fixed-art-compatible bow-only variant if using these bodies; standard Skeleton Archer’s extra daggers are not drawn.
- Enemy refinements above select Veteran/Knight/Guard foundations with matching real equipment; Spy traits for Assassin; ordinary unarmed Bruiser/Brawler; Wolf intrinsic Bite and selected traits for Shepard; and actual spells/items for the casters. These are curated proposals, with incompatible canonical grants explicitly removed.
- Enemy `Shooter`, `Sniper`, and top-down `Zombie Soldier 01–05` select the shared carried-longgun concept above. Faithful execution still requires authored native firearm content and compatibility checks; those remain a capability gap without crossbow substitution.
