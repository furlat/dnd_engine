## Shared production work, not absent assets

1. **Retained semantic discriminators and provenance.** [ConditionState](/mnt/c/users/tommaso/documents/dev/dnd_engine/dnd/types/actor.py:30) exposes energy/size/ability but no metamagic mode, shield kind or Shillelagh weapon selection. [ActionFact/SpellFact/save/damage facts](/mnt/c/users/tommaso/documents/dev/dnd_engine/game/player_facts.py) establish existing passive boundaries. Feature success must be retained from native results, never inferred through private class access or names. This is engine work that new art cannot fix.
2. **Current-pose material adaptation.** [item material path](/mnt/c/users/tommaso/documents/dev/dnd_engine/game/item_effects.py) already preserves palette zones/alpha and adds bounded bloom. The delivered Shillelagh operator adds animation and exact item ownership; the delivered Barkskin/Rage operators sample material within current posed alpha. Port these as shared passive presentation operations, preserving source gear and slot order. The browser's JavaScript class layout is reference math, not permission to import an alternate renderer or gameplay OOP layer.
3. **Existing attachment and phased media paths.** `ConditionLayer` already supports body/ground/head/face; `animation_draw.pose_attachment_anchors` resolves poses. Sensory has explicit projection/pivot registration. Holds have independent chain phases and Paralyzed operator. These need data and lawful fitting, not invented new socket systems or body copies.
4. **Source-owned moving areas and hands.** Antimagic/Presence follow authoritative world membership. Telekinesis follows actual forced displacement and terrain support. Preview five destinations, 49 mist patches, approximate mouth/hand coordinates and fixed human height are examples, not gameplay data.
